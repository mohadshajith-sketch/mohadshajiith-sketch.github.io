# Photography & Graphic Design Portfolio

A responsive, single-page portfolio website with premium black-and-white styling and a lime accent.

## Included
- `index.html` — website page and styling
- `assets/` — the three photography collages you uploaded

## Before publishing
1. In `index.html`, replace `Mohamed Shajith` with your display name.
2. Replace `your.email@example.com` with your real email address in both the email link and any visible contact text if you add it.
3. Replace the three sample poster concepts with your real poster projects before applying for jobs. The current posters are clearly marked as placeholder concepts.
4. Check that you have permission to show every photograph publicly.

## Publish free with GitHub Pages
1. Sign in at https://github.com/ or create an account.
2. Create a new **public** repository. For a personal site, name it exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html` and the whole `assets` folder to the repository root. Do not upload only the HTML file.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main`, folder `/(root)`, and click **Save**.
7. Wait a few minutes, then visit `https://YOUR-GITHUB-USERNAME.github.io`.

GitHub Pages sites are public on the internet. Do not include private information. GitHub's official guide: https://docs.github.com/en/pages/quickstart
